# Python Libraries

V3 එක modern desktop UI එකක් නිසා main library එක **PySide6-Essentials (Qt)**.

```text
PySide6-Essentials  modern UI, table, grid/list, drag/drop, dark/light, dialogs
Pillow      image/template/output processing
PyInstaller optional Windows EXE build
```

Install:

```powershell
py -m pip install -r requirements.txt
```

`run_windows.bat` first run එකේ automatically check/install කරනවා.
