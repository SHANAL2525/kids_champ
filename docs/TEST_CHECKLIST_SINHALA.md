# V3.1 Test Checklist — Office PC

මේ build එක publish version එකක් නොවෙයි. මේ steps ටික test කරන්න.

## Generator
1. `run_windows.bat` run කරන්න.
2. Sample ZIP හෝ real ZIP upload කරන්න.
3. Upload වුණාම **first final output preview auto show** වෙනවද බලන්න.
4. Batch row එකක් click කරලා preview shake/jump අඩුද බලන්න.
5. Edit icon click → ID / Name / Location / Template change කරලා outside click කරන්න.
6. Delete icon click → එක row එක විතරක් remove වෙනවද බලන්න.
7. Name search කරලා same-name results `1 / 2` navigation check කරන්න.
8. Auto / Portrait / Landscape / Square check කරන්න.
9. `Clear All` → rows + thumbnails + final preview + count visually disappear වෙලා upload `+` state එක ආපහු එනවද බලන්න.
10. Download All → output folder + ZIP generate වෙනවද බලන්න.
11. Generate වෙද්දී Cancel test කරන්න.

## Template Settings
1. Page open කළාම Landscape default auto-load වෙනවද බලන්න.
2. Portrait card එක single click → middle Visual Editor + right Template Properties load වෙනවද බලන්න.
3. Grid/List switch → group hierarchy + selected template preserve වෙනවද බලන්න.
4. New Group create කරන්න → group heading එක top, content area ඒ යට show වෙනවද බලන්න.
5. Template එක drag කරලා custom group එකකට move කරන්න.
6. Ctrl + Click templates multi-select → right-click Duplicate/Lock/Move test කරන්න.
7. Default locked template Delete → strong protected warning show වෙනවද බලන්න.
8. New Template → Name / Type / Image required validation test කරන්න.
9. Template Editor → Artwork / Name / Location box drag + resize.
10. Save Changes → confirmation → saved preview/thumbnail update.
11. Light / Dark mode both pages check කරන්න.
